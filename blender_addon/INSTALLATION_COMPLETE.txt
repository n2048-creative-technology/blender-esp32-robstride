For end users (SIMPLEST):

  unzip robstride-streamer-0.1.1.zip
  cd robstride-streamer-0.1.1
  python3 install_addon.py

That's it! The script handles everything.

Then:
  1. Restart Blender
  2. Go to Edit → Preferences → Add-ons
  3. Search for "RobStride" and enable it
  4. Look for RobStride panel in 3D View (press N)

💡 TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• For users who don't have Python installed, they can still use manual
  installation by extracting the addon ZIP to the addons folder.

• Always keep the dist/ packages for distribution. Don't distribute
  the raw addon folder - use the packaged versions.

• If pyserial doesn't install, try:
  blender --python-expr "import subprocess, sys; \
  subprocess.check_call([sys.executable, '-m', 'pip', \
  'install', '--force-reinstall', 'pyserial'])"

• For troubleshooting, see INSTALL.md - Troubleshooting section
