HOW TO USE:
================================================================================

FOR END USERS (EASIEST - One Command):
  
  unzip robstride-streamer-0.1.1.zip
  cd robstride-streamer-0.1.1
  python3 install_addon.py

FOR ADVANCED USERS (Manual):
  
  unzip robstride-streamer-addon-0.1.1.zip
  cp -r robstride_streamer ~/.config/blender/4.0/scripts/addons/

FOR DEVELOPERS:
  
  tar -xzf robstride-streamer-0.1.1.tar.gz
  pip install -e .

FEATURES:
================================================================================

✅ Stream real-time animation to ESP32 motors
✅ Support up to 32 motors with individual configuration
✅ Map any animation channel (Loc/Rot X/Y/Z) to motors
✅ Adjust motor gains (Kp, Kd) and torque
✅ Monitor real-time telemetry
✅ Loopback mode for offline testing
✅ Automatic dependency installation
✅ Cross-platform support (Linux, macOS, Windows)

INSTALLATION SUMMARY:
================================================================================

Easiest way for all users:

  1. Download robstride-streamer-0.1.1.zip
  2. unzip robstride-streamer-0.1.1.zip
  3. cd robstride-streamer-0.1.1
  4. python3 install_addon.py
  5. Restart Blender
  6. Enable addon in Preferences → Add-ons
  7. Open RobStride panel (press N in 3D View)
  8. Configure and start streaming!

Time needed: 2-3 minutes total
