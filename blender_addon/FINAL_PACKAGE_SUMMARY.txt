🛠️ BUILD PROCESS
══════════════════════════════════════════════════════════════════════════════

How the package was created:

1. Create virtual environment
   → Used for building wheels in isolation

2. Install dependencies
   → pip install pyserial

3. Build wheels
   → pip wheel --wheel-dir ./wheels pyserial>=3.5
   → Creates: pyserial-3.5-py2.py3-none-any.whl

4. Create package
   → Copy addon source
   → Copy wheels
   → Copy documentation
   → Create install.py script
   → Create manifest
   → Zip everything

5. Clean up
   → Remove temporary files
   → Remove venv
   → Keep only the .zip

Result: Single self-contained package ready to distribute!
